# Phase 27c node builder — experience

## Purpose and scope

Help an author see and edit the approved definition's possible paths before submitting a new immutable version. The owner requested an editable connected node interface within the ongoing Phase 27c. Both arms are possible paths; the diagram never predicts a model result or grants a capability.

## Author journey

1. Start blank or from a template and enter Basics and Inputs.
2. Inspect the graph; select a tool, model, branch or answer node to edit its details in the adjacent inspector.
3. Add a node and connect its output to a following input. Click both ports for keyboard/touch or drag between them. Choose each branch arm independently.
4. Check connection errors and the textual edge summary. Invalid connections do not overwrite a draft. Removed or renamed targets produce explicit errors until fixed.
5. Test the draft with supplied samples only, then review all tool risks, model caps, the declared total cap and time limit.
6. Confirm Save. PostgreSQL validates the entire definition and derives capabilities; a different approver must approve it and its runtime key.
7. An approved owned version can make a separately confirmed real model preview, using private tool samples. It cannot dispatch tool actions.

## Other journeys

An approver or Hub viewer sees a read-only diagram and definition details through existing authorized reads. Existing schema-v1 definitions keep the original sequential form until the author explicitly enables the full builder. Stale-save refusal retains the draft and offers a separately confirmed copy.

## Boundaries and recovery

Only forward edges to unique ids are accepted by the local connector. Server validation remains authoritative for reachability, dominance, capability and all terminating paths. Draft graph edits make no API writes. External drag content is ignored. Page reload loses unsaved local work under the existing memory-only policy. Save/preview refusals retain the server's explanation; no automatic retry, approval or external execution is introduced.
